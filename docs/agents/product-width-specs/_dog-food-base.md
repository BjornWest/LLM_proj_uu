# Dog dry-bag supporting module

Status: supporting authoring module, not a registered concept. Owned alongside
`dog_food.dry_food`; no shared compiler or accepted cat-food module changes.

The module retains only canonical parent/brand identity, neutral positioning and
execution, a synthetic one-kilogram price anchor and sparse bag manufacture. It
does not supply species, target, formulation, nutrition or owner statements.

Budget/mainstream/premium positioning uses supplied brand weights; execution is
uniform0.05–0.95. Price bands are40–90/80–150/140–260SEK, rounded to1SEK. Sparse
1/3/8/14kg bag menus use weights3/4/3/2 and counts1/2/3/4 weighted35/40/20/5.
Net mass is stored as1000/3000/8000/14000g; dimensionless price coefficients are
1/2.7/6.4/10.5. Exact bag price is the anchor times its coefficient. These choices
are explicit tunable authoring assumptions, not observed market distributions.

Only net mass is a grouping axis. Identity, parent, coefficient and exact price
remain canonical facts during sparse/sold-out/empty retailer projection. The
selected bag's review purchase price and both normalization bounds use the same
coefficient; a smaller bag is not necessarily better value. Animal target body
weight, daily portion, package shipping mass and inventory are separate data.
