# Neutral phone identity and canonical configuration base

Status: additive authoring module, 2026-10-01; not a counted concept or production
phone consumer. Frozen colour-only headphone and walking bases are unchanged.

The base provides model/brand identity, independent positioning/execution,
SEK reference-price bands and the canonical phone SKU schema. Hardware assemblies,
unknown disclosures, supported storage menus and colour manufacture are child
semantics. `storage_gb` and `colour` are the actual permitted grouping keys; nominal
storage labels, constant/unknown model RAM, storage factor and exact reference
price remain canonical facts. Retailer carry/stock never changes manufacture.

Nominal storage uses an explicit decimal comparison convention: 1 TB = 1000 GB,
with original labels retained. It is not usable disk space or a binary conversion.
Unknown RAM is a status, not zero or an invented selector. Reference factors stay
anchored to the full allowed model menu even if its cheaper capacity is absent.
Whole-device, display, electrical-charge/energy and update quantities are separate
typed child fields; model-specific unknowns do not inherit headphone properties.

The input fixture is an isolated authoring brand with explicit eligible concept
and positioning weights. Preview allocation overrides current-concept eligibility
deliberately; neither this fixture nor a report establishes production brand scope,
device compatibility, renderer/task integration or empirical market probabilities.
