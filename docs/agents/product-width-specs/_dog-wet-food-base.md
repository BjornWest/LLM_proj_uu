# Dog wet-pack supporting module

Status: supporting authoring module, not a registered concept. This new module
does not modify the accepted dry-dog or cat-food modules.

Neutral identity, supplied positioning weights and uniform execution0.05–0.95
are reusable. Synthetic one-kilogram price bands are45–90/80–180/160–320SEK,
rounded to1SEK. The inheriting concept supplies its joint recipe, same-formula
manufacture and unit mechanisms; this module alone is not a product recipe.

Canonical records preserve unit food grams, dimensionless count, total grams,
dimensionless price coefficient and exact reference SEK. Only unit mass/count
are retail grouping axes. Typed intermediate fields derive grams×count and
SEK×coefficient before record emission; independent arithmetic remains required.
Sparse manufacture and retailer listing are separate; no stock, shipping,
feeding ration or subscription is sampled here. Review price normalization uses
the selected canonical pack's price and coefficient-scaled bounds.
