# Neutral phone-case authoring module

`_phone_cases_base.json` provides model/brand identity, independent positioning and
execution, reference-price bands and canonical colour/device-ID SKU fields. Exact
supported-device ID is a canonical fit fact, not a cosmetic selector. Only colour
is a retail grouping axis. Child concepts author compatible-device/construction
facts, box contents and nonempty manufacture. No phone performance, retailer price,
stock or delivery guarantee is inherited.

The shell recipe uses SEK70–180/150–400/300–900 positioning bands rounded5. Its
construction probabilities share positioning, with nonzero alternatives; execution
remains separate. Child review programs use selected canonical-SKU price and global
SEK70–900 value bounds. The shared75% silent/concentration1.5 and modest relative-price
value policy remains unchanged. A later folio may explicitly replace bands/schema
rather than invent inherited card capacity or closure features here.

Device fixtures are named authoring declarations, not real vendor hardware or a
runtime join to `phones.smartphones`. Production phone/case matching and retailer/task
adoption remain deferred. Unknown protection, mass, stand and accessory clearance
are not false or zero; applicable disclosures must guard unknown values.
