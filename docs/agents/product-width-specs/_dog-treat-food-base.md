# Dog treat-pack supporting module

Status: supporting authoring module, not a registered concept. No accepted cat or
dog module is modified. Neutral identity/positioning/execution and unadjusted
synthetic one-kilogram price bands150–300/260–600/500–1000SEK are reusable. The
concept supplies format-specific price factor and all manufacture/target facts.

Canonical records use a common typed key set: unit food grams, dimensionless
outer-unit count, total grams, nominal pieces per unit, total nominal pieces,
dimensionless price coefficient and exact reference SEK. The two piece fields
have explicit numeric unknown sentinels for unreported counts; unknown is not
zero. Only mass/count are retailer axes. Derived nominal piece totals are not
individual-piece masses or calorie declarations.

Typed intermediate arithmetic preserves food grams×outer count and SEK×price
coefficient. Selected canonical pack price and both normalization bounds use
the same coefficient. There is no species, recipe, pack-menu, stock, shipping,
individual feeding-dose or nutritional-suitability assumption in this module.
