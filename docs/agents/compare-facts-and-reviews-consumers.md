# Compound comparison and review consumers

These additive Website consumers implement source preparation for Product's
`compare_facts_and_reviews` contract at `e21d510038e4cac8991b31324d81236ed879cce3`.
They do not change existing pages, shared Runtime, native selection or graders.
They are not an accepted browser runtime or a dispatched model episode.

## Publication

`catalog_compare_review_publication.generate` uses the native pre-sampling
compiler and exactly one ordinary manufacture. Two carried model identities and
their review publication identities remain native choices. Unsupported bindings
and null tasks/references are frozen without redraw or proxy-task launch.

`prepare` requires explicit `answer_grading.mode=subscription-post-run`. It reuses
the existing fresh-output writer and replaces every temporary feature-shaped
record. The final private files are:

- `catalog-compare-review-task.private.json` — whole native task.
- `catalog-compare-review-reference.private.json` — unchanged native conjunction.
- `compare-review-binding.private.json` — subject/publication binding.
- `required-obligations.private.json` — exact native roles, subjects and scopes.
- `compare-review-field-inventory.private.json` — field declarations/source pins.
- `compare-review-topic-inventory.private.json` — review vocabulary/source pins.

The source snapshot includes both field and review declaration source hashes.
`automatic_grader_supported` describes native binding only. Public readiness is
explicitly `requires_separate_runtime_audit`; native truth cannot satisfy it.

## Runtime and extraction

`CatalogCompareReviewEpisode` checks the original public task, exact private
obligations, both model review coverage bindings and sampled compositions. Its
native grader receives the complete actual world, retailer offer bindings, site
registry and surrounding corpus. One standard navigation profile preserves
ordinary discovery, pages and distractions.

`run` requires finite turn/context limits, a source-pinned public readiness
auditor and a viewer projection callable before dispatch. It closes the policy
lease and Runtime before one task-neutral extraction. It prospectively attaches
the shared `AutomaticGrading` external contract before runner dispatch, then
calls `finalize_external` once after both cleanup phases. Caller options cannot
replace that contract or enable ungraded execution. All six native inputs and source paths
are pinned by an owned deferred transaction using the unchanged shared
`task_answer.extract_and_grade`. The native conjunction and
list-shaped derivations are unchanged. Missing extraction, execution/cleanup
failure or unverified viewer projection is a system failure. There is no retry.
Post-policy source checks do not query quota to discard a completed result.
Runtime cleanup errors produce a durable system-failure result before extraction;
no success record is written while Runtime cleanup remains pending. The saved
policy task must retain the exact public task ID, request, memories and environment
context before the formatter can run. The shared gate records the native grade
and canonical Evaluation separately, with whole-run effect authorization unknown.
The installed shared grading/viewer dependency sources are pinned before dispatch.
The first answer-sidecar publication occurs after `finalize_external` finishes
writing canonical episode/evaluation files. The pending bytes and their hashes
are retained separately, with an explicit before/after binding-transition record.
No historical sidecar is rewritten or rebound. Final publication rechecks all
other inputs/sources and verifies the actual final sidecar before HTTP projection.

## Proposed public-readiness seam

The auditor callable receives `runtime`, a detached native `task` and `reference`.
Its actual callable implementation file must be present in the supplied source
pins; pinning an unrelated file does not bind the invoked auditor.
Its separately pinned implementation must inspect actual retailer publication
and the complete required independent review corpus, including pagination and
silent-rating summaries. It must return an immutable report with:

| Key | Meaning |
| --- | --- |
| `schema` | `website-compare-review-readiness-v1` |
| `status` | `sufficient`, or a rejected unsupported/insufficient status |
| `task_id` | Exact native task identity |
| `runtime_binding_sha256` | `public_binding(runtime)`, covering world, complete bindings, registry, compositions and public retailer/review payloads |
| `files` | Absolute public-document artifact paths mapped to SHA-256 |
| `roles` | Exactly one record per native obligation: `role_id`, `product_id`, `source_family`, `status`, `document`, nonempty `locator` |

`check_readiness` verifies this envelope, artifact pins and all role identities.
For retailer roles it retains each native known/unknown/not-applicable status;
it rejects substituting unknown for an omitted known fact. Every review role
requires a known information source. Artifact locations describe availability,
not main-agent observation or attention.

**The envelope checker is not the semantic auditor.** No accepted auditor or real
public sufficiency receipt exists yet. The auditor and its exact source union
need independent acceptance before launch. Synthetic witness HTML in the tests
deliberately does not contain real fact evidence and cannot release that hold.
No callback, recording or effect authority is inherited from Address.
